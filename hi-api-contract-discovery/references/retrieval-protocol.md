# API Retrieval Protocol

Use `mind_mcp` , `graph_mcp`, scoped graph semantic candidates, verified graph relationships/full-stack paths, Serena confirmation, then `rg` for route strings, annotations, DSLs, generated configuration, schemas, or topic identifiers. Fast-fail unavailable capabilities once.

Verify graph repository/project/database/collection identity before accepting results. Trace registration to handler, input parsing/validation, authorization, response/error, caller/consumer, service, persistence, and external dependency when available. Route or topic declarations seed investigation but never prove a complete contract.

Record dynamic routes, reflection, middleware, generated clients, schema drift, and missing consumers as gaps. Never expose real tokens, identities, infrastructure hosts, connection strings, or payload values.
